# Archive

This folder holds the full source of the previous version of this site
(multi-page resume/portfolio, with About, Experiences, Skills, Contact,
and a small game) before it was replaced with a minimal landing page.

It is kept for reference only — it is **not** built or deployed. It has
its own `package.json` and would need to be moved back to the repo root
(replacing the current `src`/`public`) to run again.
